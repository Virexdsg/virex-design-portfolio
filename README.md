# VIREX DESIGN — GitHub Pages

Содержимое этой папки — готовая статическая версия сайта. Загрузите все файлы и папку `assets` в корень репозитория GitHub. Главная страница — `index.html`.

Видеоролик и оригинальные изображения хранятся в `assets/`; `styles.css` и `script.js` подключены отдельно. Не загружайте только `index.html`: для сайта нужна вся папка `assets`.

Чтобы опубликовать сайт, в настройках репозитория выберите GitHub Pages, источник публикации — ветка репозитория и корневая папка (`/`).
